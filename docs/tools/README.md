# Ash Tools

Ash currently provides one executable:

- [`ash`](ash.md) runs a modular entry or builds a native program with `ash build`.

The [pure computation microbenchmark](../../benchmarks/pure/README.md) compares
source execution, generated-host builds and execution, and equivalent Python
programs, recording wall time, CPU time and peak resident memory.

Tool behavior derives from the retained implementation and tests. Language
semantics remain in the [canonical specification](../../spec/README.md).
