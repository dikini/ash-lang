# Scalar in-process closure architecture evidence

[AD-0015](../../../../decisions/AD-0015-linux-scalar-inprocess-whole-images.md)
selects the narrow owner-free scalar GNU in-process architecture. The
[owner acceptance readback](acceptance-receipt.json) records explicit delegated
acceptance after independent preparation review. This evidence creates no
per-image strict approval, startup authority or configured deployment.

The [exact closure premise example](closure-premise-example.json) is preserved
byte-for-byte from the reviewed proposal. Its PROPOSED/non-authorizing status is
intentional: it demonstrates data associations, not an approved executable
record or a second authority mechanism. It binds the actual existing-profile
baseline and immutable producer receipt. That baseline supplies no checked
contract closure and cannot approve checked execution. Its null administrator
context and pending admission-work mechanism must not be accepted by a product
launcher. F6 must implement those associations and refuse their absence.

original text, supports a conditional

under `/tmp/ash-checked-ffi-inprocess-design/glibc-source-audit`; the repository
does not vendor glibc/Rust sources or claim every recorded external file is
present here. Official immutable source links are in the conclusion. The full
manifest includes historical failed-fetch metadata and acquisition scripts;
those are provenance, not product tools or execution instructions. Source
retrieval does not reproduce the patched distribution build or establish all

Transferred [generated Ash packaging](../generated-ash/README.md) and
[separately approved diagnostic](../generated-ash/diagnostic-addendum.md) retain

That diagnostic accepted possible loading. Its approval is inapplicable to the
strict closure policy. No original producer receipt, policy, approval, harness

The decision accepts trusted runtime/native closure conformity as an explicit
in-process premise; structural ELF facts, conditional source evidence and this
premise remain distinct. Nine temporary link inputs are missing and the Ubuntu
source import is patches-unapplied. These limits are bound in the example.
No formal whole-libc guarantee, trace-derived proof, isolation or protection
against faulty native memory is asserted. Strict per-image approval, protected
store/context enforcement and connected F4/F6 implementation/tests remain
pending. Whole F2 criteria remain unchecked.
