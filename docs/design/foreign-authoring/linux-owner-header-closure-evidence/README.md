The baseline's stored-data read is not native memory access. Digests bind
review inputs; they do not prove allocator behavior, full loading exclusion,
native integrity, truthful disposition, source completion or host-loss cleanup.

This is data for later independent premise/owner-decision review, using the
existing producer receipt and independent protected approval mechanism. It adds
no registry or self-authorizing flag. The null deployment context and unselected
argv cannot authorize startup. No scalar or possible-loading diagnostic approval
is reusable as ownerful strict approval. The exact legacy baseline supplies no
checked contract closure. A later trusted diagnostic, if separately prepared and
assigned, must freeze actual expected outcomes and applicable premises.

[Retention index](retention-index.json) maps every exact original and external
omission. Original absolute paths and historical statuses remain unmodified;
these are evidence, not portable commands or replay authorization. The original
16-file preparation and 32-file execution inventories for each gate overlap;
they must not be summed as distinct observations. System headers/tools, full
source/native archives, giant maps/images and cache are omitted with exact pins.
No source audit input is rewritten or silently upgraded to proof. Missing
external bytes limit repository-only reconstruction.

Whole F2 and all four original issue58 criteria remain unchecked. Ownerful
architecture/native closure/startup, checked reservation/guard/quarantine/copy/
