## Discoveries

The current unary assumption spans surface and resolved declarations, checked
facts and summaries, requirements and implementation heads, evidence plans and
slots, linked validation, elaboration, and Core authentication. Vectorizing the
complete semantic carrier path is unavoidable. Encoding arity as a tuple would
lose independent higher-kinded arguments and canonical parameter identity,
kind, origin, and order.

The total-key restriction removes edge graphs, closure, chained improvement,
projection normalization, and per-edge coherence. Effects, proofs, and
existentials pressure complete typed applications and encapsulated evidence
producers, but do not justify implementing their semantics in this task.
