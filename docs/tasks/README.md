# Tasks

Tasks plan and record active implementation work authorized by an accepted change proposal or architectural decision. They may record dependencies, work, progress, verification, discoveries, and deviations. They never define language semantics.

Use [the template](template.md) and allocate the next `TASK-NNNN` ID. No implementation task is active yet; see the [trajectory](../trajectory.md) for the design evidence needed before tasks can be authorized.
