## Invariants and exclusions

Preserve passive modules, existing-profile static/shared builds, exact source
identities, canonical builtin roles, source work calibration, startup limits,
non-suspending windows and the prohibition on arbitrary State/view helper
transport. No native pointer enters a source value or report. Unknown native
consumption never becomes consumption or another teardown attempt. Committed K
does not erase the required source finish continuation. Mandatory history cannot
be replaced by optional diagnostic strings.

selected/generic closure, other byte/NUL/window cases, SQLite and F7 containment
remain open; reject an unsupported required contract before activation. This
subset does not waive runtime quarantine/loss obligations for its supported
paths. Any concrete semantic ambiguity returns to CP/design rather than a local
completion rule. A later full F-core gate must connect acquisition, call, copy,
completion and admission; this task may claim only the controls actually passed.
