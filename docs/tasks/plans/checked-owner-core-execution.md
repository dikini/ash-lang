## First connected program

Reduce the supported checked-byte source fixture to one dependency-free owner,
one direct provider copy handler and one exact byte window. Use qualified
builtin names, real CheckedCall/CheckedFinish/CheckedScope identities, selected
H distinct from fresh R, public acquisition codec and complete retained formals.
Finish performs exact Free once, then Trace, then forwards its genuine outcome;
BoundaryFailed forwards the original reason. Preserve typed impossible arms
without granting them witnesses. Return copied Bytes outside R/H only after
finish; source data is Unit, not a stored substitute for native bytes.

A new small C test library exposes an acquire helper, release, view and length
functions. Acquire accepts capacity 8, uses calloc and writes a fixed eight-byte
pattern such as [5, 255, 0, 65, 66, 67, 0, 9] before returning nonnull. Other capacities
refuse. The source initialized_bytes promise is exactly 8. View/length use the
same admitted Current and key 0, return only that allocation's byte interval
and extent 8, and free consumes that compatible pointer once. No parent owner,
ambient environment/file IO, callback/thread creation or arbitrary pointer
transport is required. Pin helper source/header/archive/build and check actual
ABI/target/header closure; the prior malloc/free header check is not a proof of
these new prototypes. A finite trusted native contract remains explicit.

Assert the exact copied bytes, including embedded zero and 255, after owner
finish/Trace. A marker for a native attempt is not proof of disposition truth.
The product has no library-name special case. The initial public example omits
NUL, write/read scalar handlers and arbitrary helpers to keep the required
closure small; their existing tests remain regressions and broader acceptance
remains open.

## Required distinguishing controls

- Canonical pipeline first; then body-free required-fact omission, wrong selected
  H/R, coherent donor view/Extent/key, wrong codec/vector/host selector, erased
  Host/Trace rows and stale copy/finish maps reject at their actual independent
  boundary. Do not credit parser/setup or Resource errors as semantic negatives.
- Checked native null refuses without a published owner; genuine initialized
  nonnull copies the exact eight bytes and finishes once. Index/extent/key/range
  errors publish no partial Bytes. Copied independent Bytes survive finish; State
  and views do not escape, and post-finish access rejects.
- Pre-entry mandatory capacity/work one-short means no native attempt. Measured
  exact/prefix/one-short/spent/fresh controls preserve meters and original inputs.
  Fault injection after native return/consumption but before source report must
  retain committed facts, avoid replay/double free and separate evaluator failure
  from BoundaryFailed. Required finish Trace runs even on a witnessed boundary
  alternative; forged/missing/duplicate/earlier-call completion cannot discharge K.
- Two independent groups under one H do not share quarantine/identity. A violation
  retires that group's aliases/windows and preserves unresolved backing; it does
  not manufacture consumption or quarantine an unrelated group. No dependency
  spanning separate groups is silently supported.
- Approval/store/context absent, writable, linked/replaced, wrong namespace/user
  association, stale receipt/premise/version/mode, altered image/native/header/
  payload/facts/operation mapping and insufficient bounds refuse before selected
  foreign initialization/acquisition. Final immutable fd hash/ELF equals approval;
  original-path replacement and sealed mutation cannot change executed bytes.
  Do not execute unapproved substitution artifacts to prove their rejection.
