# Pinned worker: fresh assembled workspace gate

This receipt records the no-reuse workspace gate run for the N2 assembled
candidate. It does not by itself establish whole-issue acceptance or prove the
Rust implementation. The [focused runtime receipts](README.md), the separately
retained [modeled source gate](../pinned-one-way-proof/README.md), and the
[implementation correspondence](../../../design/retained-control/one-way-completion-correspondence.md)
retain their own scopes.

## Run and results

The gate ran in the delivery checkout with an offline Cargo environment, one
build job, an empty `RUSTC_WRAPPER`, the shared target directory, and a private
`TMPDIR`:

```sh
CARGO_NET_OFFLINE=true RUSTC_WRAPPER='' CARGO_BUILD_JOBS=1 \
  CARGO_TARGET_DIR=/home/dikini/Projects/ash-lang/.worktree/generic-cells/target \
  TMPDIR=/home/dikini/Projects/ash-lang/.worktree/generic-cells/target/ash-ncore-gate5-tmp \
  cargo xtask verify --receipt-dir /tmp/ash-ncore-assembled-receipts5
```

All seven stages completed successfully and each stage receipt records
`reused: false`. Total elapsed time was 1,153.824 seconds.

The test stage includes 1,764 passing library tests and 47 passing architecture
