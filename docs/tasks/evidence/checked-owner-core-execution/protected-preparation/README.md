## Storage and audit

`provenance.json` maps original external bytes/hashes to retained blobs;
`execution-associations.json` maps actual run inventory, and `omissions.json`
labels every omitted paired wrapper/cache/large map/binary. Exact identical blobs
are deduplicated and deterministic gzip preserves patches losslessly, including
context whitespace. Large source-map JSON objects use `map-index.json` base+
changed/removed deltas; JSON templates reconstruct the exact original bytes.
`verify.py` checks the complete payload manifest and decodes/hashes every
provenance record. This encoding is evidence storage only, not a product parser
or authority mechanism. External originals may be rechecked with `--external`.
Current task/plan/README and evidence were assembled after tests; the 37 tested
non-prose source/fixture pins remain exact. Historical tested manifests keep their
original meaning; none is labeled as the post-assembly full repository map.
