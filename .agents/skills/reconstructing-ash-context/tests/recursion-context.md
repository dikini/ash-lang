# Recursion Context Scenario

## Request

The first Mini-Ash increment is implemented. Begin design work for a retained
increment that adds recursive function definitions. Reconstruct enough Ash
context to explain the problem before proposing semantics, architecture, or an
implementation plan.

## Expected semantic model

A useful synthesis explains relationships rather than listing documents. It
must identify:

- that recursion is absent from current Ash and requires a semantic proposal;
- stable binder identity and the difference between ordinary nonrecursive scope
  and the proposed recursive scope;
- recursive checking, monomorphic recursive use, and later generalization
  pressure;
- the typed Core construction and independent-validation boundary;
- closure or environment representation, including how a function reaches its
  own binding without relying on a Rust closure;
- the explicit evaluator machine and the distinction between ordinary recursive
  calls and future capturable continuations;
- transferable primitive-feature evidence that feature behavior localized more
  readily than cross-stage representations;
- that Float operator ownership, CLI admission, and build-feature selection are
  not recursion requirements;
- whether recursion can elaborate through existing binding and function forms
  before assuming a new Surface, Core, or evaluator family.

The synthesis may use different sources or wording. It fails if it merely
recites authority, reads the nearest linked artifacts, or imports every Float
mechanism because the experiment is marked relevant.

## Baseline

The original context-reconstruction skill fails this scenario as an
instruction. It optimizes for the minimum number of sources, routes primarily
by artifact class and direct links, and stops when named factual gaps are
filled. It does not require a causal semantic model, a contrary-pressure
challenge, transferable experimental evidence, simplification analysis, or an
explanation of intentional exclusions.

That text permits an agent to stop after the current specification, trajectory,
front-end/Core/evaluator decisions, and the closest recursion sections. Such a
reading can satisfy the stated route while missing both the general Float
finding and the possibility that recursion lowers through existing forms.

## Passing condition

The revised skill passes when following it necessarily produces the semantic
relationships and relevance judgments above without prescribing this exact
document list, exact prose, or a persistent intake checklist.
