# Pure computation results: 2026-11-01

Measured on an AMD Ryzen 7 7435HS with Python 3.12.9 and Rust 1.97.1.
Ash and generated hosts use the release profile with optimization level 3.
The compiler/runtime source snapshot is
`2725cc2c01770ab318ec29c54e0263cedeab05f4`; exact source, compiler and host
hashes are retained in `target/pure-benchmark/2026-11-01-measured/results.json`.
The raw receipt is local and is not published.

Execution figures are medians of five fresh processes after one warmup per
case and lane. All 45 measured outputs and nine warmup outputs matched.
CPU is user plus system time. RSS is peak resident memory, including code
and runtime pages. Wall and CPU include the small GNU time monitor overhead.

The initial native-cache setup took 317.166 s wall,
316.585 s CPU and 2140.828 MiB peak RSS.
This separate setup is not included in the warm-cache build samples.

Build samples and cache setup transfer unchanged from the original run,
before unrelated compiler-source edits appeared in the shared checkout.
Their direct `wait4` RSS peaks exceed the established 19.75 MiB driver
floor and are therefore unaffected by that floor. The original execution
RSS readings were superseded. Execution was remeasured with the native
monitor against the same pinned compiler and host binaries. Source and
artifact hashes establish this bounded transfer; the current dirty
compiler sources were not rebuilt for these execution samples.

The built host reconstructs checked Core and uses the same evaluator.
These results cover the fixed workloads and whole-process boundaries in
the [benchmark guide](README.md); startup and checking contribute to the
figures. They do not establish a general language performance ranking.

The final measurement command was:

```sh
RUSTC_WRAPPER= python3 -B benchmarks/pure/run.py \
    --reuse-builds target/pure-benchmark/2026-11-01-verified/results.json \
    --output target/pure-benchmark/2026-11-01-measured
```

Use the guide's default command to collect new builds on a matching
compiler checkout. Use a new output directory for each run.
